# 02 · 读取：方法与类型识别

> 读不到通常不是权限问题，而是"用错了方法"或"传错了 area"。
> 这一页给你一套先识别类型、再取值、最后校验状态的流程。

---

## 1. 六种取值方法

`CarPropertyManager` 和 `CarCabinManager` 通常都有：

| 方法 | 返回 | 适用 |
|---|---|---|
| `getIntProperty(id, area)` | int | 大多数厂商属性、开关、挡位、枚举 |
| `getFloatProperty(id, area)` | float | 转速、车速、温度、电量 |
| `getBooleanProperty(id, area)` | boolean | 门锁、充电口、ABS、白天黑夜 |
| `getStringProperty(id, area)` | String | 版本号、部件号 |
| `getBytesProperty(id, area)` | byte[] | VIN、MCU 隧道帧 |
| `getIntArrayProperty(id, area)` | int[] | 时间、故障码、多区数据 |

有些版本还有 `getVecProperty`（返回 `Object[]`），用于混合类型。

---

## 2. 万能读法：先识别类型

不知道属性是什么类型时，用 `getProperty`：

```java
CarPropertyValue v =
        (CarPropertyValue) getProperty.invoke(property, propId, areaId);

Object value  = v.getClass().getMethod("getValue").invoke(v);
int    status = (Integer) v.getClass().getMethod("getStatus").invoke(v);   // 0 = OK
long   ts     = (Long) v.getClass().getMethod("getTimestamp").invoke(v);   // 单调纳秒
```

然后按返回的 Java 类型决定后续用哪个方法：

| `getValue()` 类型 | 后续用 |
|---|---|
| `Integer` | `getIntProperty` |
| `Float` | `getFloatProperty` |
| `Boolean` | `getBooleanProperty` |
| `String` | `getStringProperty` |
| `byte[]` | `getBytesProperty` |
| `int[]` | `getIntArrayProperty` |

**先读一次 `getProperty`，再决定调用哪个 getXxx**，可以避免大量类型错误。

---

## 3. status 和 timestamp

`CarPropertyValue` 除了值，还带两个重要字段：

- `status`：`0` 表示正常，非 0 表示属性不可用/暂不支持；
- `timestamp`：单调纳秒，用于判断值是否更新。

使用建议：

1. 读到的 `status != 0` 时，不要把它当有效值；
2. 缓存上一次的 `timestamp`，两次相同说明没更新；
3. 对比操作前后的值和时间戳，是判断"写有没有生效"的主要依据。

---

## 4. 订阅变化

对连续变化或关键状态，用订阅比轮询省电且实时：

```java
// 注册
registerCallback.invoke(property, propId, 0 /* 采样率 */, callback);

// 回调里拿 CarPropertyValue
// 注销
unregisterCallback.invoke(property, callback);
```

注意：

- 回调可能在你注册时立刻回放一次缓存值；
- 断开/重连后要重新注册；
- 回调线程不是主线程，UI 更新要切回主线程。

---

## 5. 读取流程建议

```
1. 从枚举结果拿到 id 和 areas
2. 选一个 area（多区属性先试第一个）
3. getProperty(id, area) 探测类型和 status
4. status == 0 → 用对应的 getXxx 读取
5. 记录 value / status / timestamp
6. 如果值不合理 → 检查 area 是否选错、单位是否需要换算
```

---

## 6. 常见读取问题

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 返回 null | 属性不存在 / 未注册 | 回到枚举结果确认 |
| 返回 -1 | 不支持或未实现 | 换 area 或换属性 |
| 值一直不变 | 缓存 / 需要订阅 / 下层没实现 | 订阅或操作车辆后重读 |
| 类型不匹配异常 | 用了错误的 getXxx | 先用 `getProperty` 识别 |
| 多区属性只有一个区有值 | area 选错 | 遍历 `getAreaIds()` |
| 数值看起来是整数 | 原始值需要换算 | 记录原始值，反推公式 |

---

## 7. unit 与换算

VHAL 的原始值**不一定带单位**。常见情况：

- 温度是缩放整数（如 `raw × 0.5 − 40`）；
- 油量/电量按 mL 或未标定单位；
- 角度、转速、速度可能是 float，也可能放大 10/100 倍。

做法：

1. 记录原始值；
2. 找参考值（仪表显示、官方文档、两次不同状态）；
3. 反推线性关系；
4. 在代码里集中写换算函数，不要散落在各处。
